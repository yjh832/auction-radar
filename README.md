# 竞价雷达 · 涨停基因策略

纯浏览器 A 股集合竞价研究面板。没有后端、数据库或云盘；候选数据随静态站点发布，实时行情由浏览器直连新浪公开行情接口，计算和缓存全部在用户设备本地完成。

## 运行

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm start
```

构建产物位于 `dist/`，可以部署到任意静态网站托管服务。

## 功能

- 每日唯一推荐：模型分扣除风险惩罚后排序。
- 权限范围：只筛选沪深主板（沪市600/601/603/605，深市000/001/002/003）；
  创业板、科创板、北交所及其他板块不进入推荐和候选池。
- 9:15—9:30 打开或点击页面时，浏览器直连全市场行情并重新计算 9:25 推荐。
- 9:25后读取候选股买一盘口，计算封单量、封单金额、封单占流通市值和打板推荐值；
  强封板与竞价可执行性分开显示，避免把接近一字板误判为可追买。
- 非竞价时段只刷新行情快照，不把收盘数据伪装成竞价结果。
- 候选池、最近一次计算结果和当前交易日快照缓存于浏览器本地。
- PWA：支持“添加到主屏幕”，Service Worker 缓存应用壳，断网时可打开上次页面。
- 风险控制：短期过热、换手过高和公告风险会扣分或进入风险否决区。
- 个股详情：点击推荐卡或候选行，查看近30日K线、MA5、成交量、实际换手率、
  成交额、振幅、市值和近期龙虎榜记录。
- 资金走势：买入自动记入本机交易流水，区分做T卖出与清仓卖出，统计净投入、
  做T收益、清仓收益、已实现/浮动盈亏、总收益率，以及首选和备选标的的平仓胜率。
- 交易纠错：流水支持撤销最后一笔和二次确认删除；持仓调整支持修改股票代码或名称，
  股数、成本与对应交易记录会同步迁移。
- 持仓换股比较：逐只比较持仓质量与未持有首选/备选，结合止损异动风险给出
  维持、观察、风险优先或9:25/9:35确认后分批置换计划。
- 综合量化：推荐票按基因模型、三图、竞价、封单、板块、流动性、动量、风险和
  龙虎榜方向评分；持仓与换股比较展示七维分项，并明确数据覆盖率。
- 次日可参与值：盘后同时评估今日强度与明日可买入条件，过高一字风险、超大封单、
  低换手和高位连板会降低可参与性，强封难买标的降为强度观察。
- 推荐风格：可在趋势推荐和打板策略间切换并保存偏好。打板策略分别展示高位股断板后
  的高低切首板/一进二接力，以及封单最强、板块情绪较好的最高接力标的。
- 近半月位置：按今日涨停前15个交易日计算低位、中位或高位启动，并同时显示涨停后的
  当前15日分位；高位补涨股不会被标记为低位首板。
- 点击任意K线查看当日5分钟分时、均价线和成交量。
- 点击龙虎榜记录查看当日买卖前五席位、席位类型、近3日活跃统计、跟随评级及次日条件动作。
- 每日收盘后从最多30只沪深主板内部模型池选出6只复盘候选和1只首选；
  次日9:25只在这6只中更新首选。

## 数据更新

每日收盘后先生成最新模型结果，再运行：

```bash
npm run refresh-preview
npm run build
```

也可以指定模型文件：

```bash
MODEL_OUTPUT=/absolute/path/optimized_monday_watchlist_YYYY-MM-DD.json npm run refresh-preview
```

`refresh-preview` 会同时更新：

- `data/strategy.json`：构建备用数据。
- `public/strategy.json`：静态站点运行时从同源加载的最新候选池。

每日完整复盘与分时归档：

```bash
npm run refresh-review
```

GitHub Actions 会在工作日北京时间约15:20自动执行同样的复盘，并部署次日候选。

## 数据边界

- 行情来自公开网页接口，可能延迟、限流或调整跨域策略。
- 页面关闭后浏览器不能保证在后台执行 9:25 计算；重新打开页面会自动刷新。
- 本项目不连接券商、不执行交易，也不构成投资建议。

## GitHub Pages 自动发布

- 固定地址：`https://yjh832.github.io/auction-radar/`
- GitHub Actions 在每次推送到 `main` 后自动构建并发布。
- `npm run publish`：构建、提交并推送当前修改。
- `npm run sync`：监听电脑端源码变化并自动提交、推送。
- 手机页面每30秒检查一次 `/version.json`，发现新构建后自动刷新。

首次发布：

```bash
npm run publish
```

持续自动同步：

```bash
npm run sync
```

## Android App

Capacitor Android 工程位于 `android/`。App 直接加载固定 GitHub Pages 地址，
因此网页功能更新后不需要重新安装 APK。

```bash
npm run android:sync
```

APK 由 GitHub Actions 自动构建并发布：

`https://github.com/yjh832/auction-radar/releases/download/android-latest/auction-radar-android.apk`
